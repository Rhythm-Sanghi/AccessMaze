# Why task outcomes matter

A page can satisfy a set of automated rules while a person cannot complete its form.
A named role-button without keyboard focus illustrates this: semantics alone do not
establish that a keyboard action reaches it or that the following application state appears.

AccessMaze records the configured action, its bounded attempt, actual focus observations,
assertion outcomes and observed transitions. Its useful question is whether this task
completed under these conditions, and which observed step prevented it.

A completed task can still contain genuine rule violations. A failed browser request
can be inconclusive rather than an accessibility defect. Neither zero findings nor
missing observations is converted into success. Field-value assertions compare real
browser values while retained evidence redacts the synthetic input.
