# AccessMaze / Hackyard engineering workspace

AccessMaze investigates whether an authored browser task reaches explicit assertions
under concrete interaction constraints. Its Windows desktop keeps projects, browser
observations and retests locally. The central demonstration is an unfocusable Continue
control, its native-button correction, and the resulting completion evidence.

Audience: developers and accessibility testers who need a reproducible interaction
failure rather than an isolated rule list. Automated findings supplement human review.
No disability simulation, NVDA result or WCAG certification is claimed.

Start with [demo script](demo-script.md), [architecture](architecture.md),
[technical evidence](technical-evidence.md) and [gap assessment](gap-assessment.md).
Competition demonstration readiness and independent release qualification are separate.
The authoritative qualification record remains ../development/status.md.
