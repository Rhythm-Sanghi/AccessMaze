# AccessMaze / Hackyard

AccessMaze tests whether an authored browser task reaches explicit completion assertions
under concrete interaction conditions. Projects, browser observations and comparisons
stay on the local machine.

The demonstration follows an unfocusable Continue control through a recorded failure,
reproduction, native-button correction and successful retest. Approved branch discovery
and reusable profiles extend that workflow without granting automatic write permission.
